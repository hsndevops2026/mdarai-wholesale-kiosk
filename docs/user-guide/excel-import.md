# استيراد المنتجات والأسعار من إكسل

الشاشة: `/admin` ← «استيراد من إكسل» (لحساب مدير فقط).

## الخطوات

1. **حمّل القالب** («تنزيل قالب فارغ») أو **صدّر الكتالوج الحالي** إذا بدك تعدّل على الموجود وترجع ترفعه.
2. عبّي ورقة **Products**. قالب المحل الأصلي (`MdarAi_Wholesale_Products_Template.xlsx`) مقبول كما هو.
3. ارفع الملف واضغط **معاينة**. المعاينة ما بتغيّر أي إشي، وبتعرض:
   - كم منتج جديد، كم منتج رح يتعدل، وكم بدون تغيير
   - الأخطاء (أحمر) لازم تتصلّح، والتنبيهات (أصفر) للعلم
4. إذا ما في أخطاء، اضغط **تأكيد الاستيراد**. الكشك بيشوف التغييرات فوراً.

## القواعد

| الموضوع | القاعدة |
|---|---|
| التحديث | حسب **SKU**. لا تغيّر SKU لمنتج موجود |
| منتجات مش موجودة بالملف | بتضل زي ما هي (الاستيراد ما بيحذف). لإيقاف منتج: `Active = No` |
| الوحدة (`Unit`) | كلمة القطعة الواحدة: قطعة، كيس، زجاجة… إذا كتبت «كرتونة» فالسعر هو سعر كرتونة |
| الكرتونة | `Pieces_Per_Carton` + `Carton_Price_ILS` (أعمدة جديدة اختيارية). النظام **ما بيحسب** سعر الكرتونة من سعر القطعة، وإذا في سعر كرتونة لازم عدد القطع |
| الأسعار | أرقام بخانتين عشريتين كحد أقصى. `12,90` مقبول |
| الباركود | خليه **نص** حتى ما تضيع الأصفار بالأول |
| كلمات البحث (`Search_Keywords`) | أسماء بيقولها الزباين، مفصولة بفواصل. **انتبه للكلمات العامة**: «لبن» على الحليب رح تخلي كل واحد بيطلب لبن (رايب) يشوف الحليب كخيار |
| ورقة `Customers` | رقم الهوية بيتشفّر لحظة القراءة وما بينحفظ. **احذف الملف من جهازك بعد الاستيراد** |
| ورقة `Customer_Prices` | سعر خاص لزبون لمنتج (قطعة و/أو كرتونة) |
| ورقة `Price_Tiers` | خصم كمية. `Customer_Code` فاضي = لكل الزباين. الشرائح الموجودة بالملف **بتستبدل** كل شرائح نفس المنتج. الشرائح ما لازم تتداخل |
| حجم الملف | حتى 10MB و20,000 صف |
